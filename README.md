# Rice Production Analysis

โครงงานวิเคราะห์ข้อมูลการผลิตข้าวรายประเทศ ปี 1961–2021 ด้วย Python

## ข้อมูล
- แหล่งที่มา: Kaggle (ข้อมูลจาก FAO)
- ไฟล์: `Rice production.csv`

## ไฟล์ในโปรเจกต์
- `Rice production.ipynb` : โน้ตบุ๊กวิเคราะห์ข้อมูล
- `Rice production.csv` : ชุดข้อมูล

## วิธีรัน
เปิด `Rice production.ipynb` ด้วย Jupyter Notebook หรือ Google Colab
